## نطاق المرجع

تستخدم الصور لتحديد:

- استغلال المساحة.
- توزيع العناوين والبطاقات والجداول.
- نوع الرسم البياني الرئيس في كل صفحة.
- أحجام العناصر والتوازن البصري.
- الهوية اللونية بالأخضر الداكن والذهبي.

الأرقام والنصوص داخل الصور توضيحية فقط. يجب أن تُستبدل ببيانات التقرير الفعلية وقواعد الاحتساب المعتمدة.

## المطابقة المطلوبة

- الصفحة الأولى: غلاف + فترة + وصف المقارنة + ثلاث بطاقات.
- الصفحة الثانية: ثماني بطاقات + رسم أعمدة زمني كبير + ملاحظات.
- الصفحة الثالثة: رسم أعمدة للمناطق + بطاقات المناطق + جدول مقارنة.
- الصفحة الرابعة: الارتفاعات الملحوظة + أعلى الإدارات + أعلى التصنيفات + الاستنتاجات والملاحظات.

لا تعتبر المهمة مكتملة قبل توليد PDF وتحويل صفحاته إلى صور ومقارنتها بهذه المراجع بصريًا.
